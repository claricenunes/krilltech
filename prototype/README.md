# Sentinela Krill — Frontend

Protótipo do frontend do Sentinela Krill (Hackathon PMI-DF 2026 / desafio KRILLTECH). Ver `MVP_ANALYSIS.md` na raiz do repositório para o escopo do MVP.

## Stack

Vite + React + TypeScript + Tailwind CSS v4 + react-router-dom.

## Rotas

```text
/                  Radar da Carteira (home)
/triagem           Triagem de Cliente Novo
/produtor/:id      Drill-down do Produtor
```

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
